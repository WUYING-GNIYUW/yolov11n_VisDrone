# DM-EFS：先多留一层细节，再按图选择预测层

**EFS 解决看不清，DFM 解决不必处处都算。** 比如，一个目标在原输入中宽 6 像素，在步长 8 的网格上还不到一格。若骨干早期的特征仍有它的轮廓，EFS 把那张较密的**真实浅层特征图**一并交给颈部和预测头；不是放大已经丢失细节的末层图。DFM 则学习「多大的目标过去在哪层定位得较准」，再从当前图预测最小和最大目标尺寸，据此决定让哪几层做预测。选的是整层，不是裁图、选块或选某几个像素。

## 训练和推理怎么走

| 部分 | 训练时依据什么 | 推理时做什么 |
| --- | --- | --- |
| EFS（图 2、§3.1） | 浅层图加入已有层；扩展后的颈和对应预测头都参加原任务训练。EFS 自身没有门控损失。 | 只用 EFS 时所有层全开，通常增加计算、显存和候选位置。 |
| 尺寸→层的票表（§3.2.1，算法 1、式 2–4） | 全层打开。标注框在**本次增强、缩放后的输入坐标**中，尺寸 `s=floor(sqrt(w*h))`。每个真框在每层有一个对应预测框；当两框 IoU ≥ τ，该层在该尺寸可投票。同图同层同尺寸最多记 1 票，逐图、跨轮累加。 | 每个有票尺寸只取票数最多的层；中间无票的尺寸沿尺寸轴用最近有票尺寸的结果填齐。表不是预先规定的步长阈值，也不是靠反向传播学出的嵌入。 |
| 尺寸控制器（图 3、§3.2.2，式 5） | 每图所有有效真框的 `s` 取最小/最大值，作为**两个单标签分类**目标。各骨干层经 1×1 卷积和全局平均池化；拼接后经过共享 FC1，两个分支各经 FC2、FC3。将两端的 focal loss 之和乘 λ，加在原任务损失上，一起反传。 | 只用输入特征，两个最大概率类别给出尺寸端点，不读标签、GT 数量、预测框或 IoU。 |
| 层选择（§3.2.3，式 6） | 不做硬选择；所有层的匹配预测都要能投票。 | 只查**两个端点**：头开这两个尺寸对应层的并集，相同时只开一层；不打开区间内所有层。论文的颈门从最细层开到「最大尺寸对应层」，给后续特征提供依赖。 |

举例：层按细→粗记为 0、1、2。若一个输入两端尺寸分别映到 0、2，那么头开 `{0,2}`，颈请求 `{0,1,2}`；若都映到 1，头只开 `{1}`，颈请求 `{0,1}`。论文中 `k` 越大分辨率越高；这里下标恰好相反。即使两张图进入同一批次，也不强迫它们走同一路。

## 可复用的接口

只依赖 PyTorch，不依赖检测框架、数据集、类别数或注册表。从 `dronebench.methods.dm_efs` 导入；[公开导出](./__init__.py)、[实现](./core.py)、[完整样例](./example.py)。`B` 是图数，`L` 是层数，`S=max_size` 是可表示的最大尺寸（输入像素）；下标始终细→粗，框为无 `+1` 的连续 `xyxy`。

| 调用 | 输入 → 输出及用途 |
| --- | --- |
| `expand_features(shallow, base)` | 两组同批次 `[B,Cᵢ,Hᵢ,Wᵢ]`，每组按细→粗 → 含新增浅层图的 tuple，保留原张量和梯度，不插值、不假定步长。颈和头必须实际消费新增层。 |
| `ExpandedPyramid(in_channels, width)(features, last_level=None)` | 可选的独立参考颈。先用 1×1 对齐通道，粗→细上采样相加，再细→粗池化、卷积、相加。返回各层 `[B,width,Hᵢ,Wᵢ]`。指定 `last_level=j` 仅执行第二趟的前 `j+1` 层；第一趟仍需所有层。已有任务可以用自己的颈，**不是**要求换掉原颈。 |
| `SizeRangePredictor(in_channels, max_size, projection_channels=16, hidden_channels=64)(backbone_features)` | 未经门控的骨干特征 → `[B,2,S-1]` logits。尺寸类别为整数 `2,…,S`（原文 `(1,S]`），下标 `s-2`。只有控制器、颈和预测头/骨干等网络层靠梯度更新。 |
| `size_range_loss(logits, boxes_per_image, weight=0.04, gamma=2.0)` | 每图一个 `[Nᵢ,4]` 有效真框张量 → 可反传标量。忽略区域、padding、退化框应先剔除；空图传 `[0,4]`。 |
| `paired_box_ious(gt_xyxy, matched_xyxy)` | 一图的真框 `[N,4]`，每真框每层配好的预测框 `[N,L,4]` → 定位 IoU `[N,L]`。配对由任务提供，代码不借用类别分数伪造定位票。 |
| `book = SizeFeatureCodebook(num_levels, max_size, iou_threshold=0.5)`；`book.observe(gt_xyxy, matched_iou)` | 一次一图、只在训练调用，`matched_iou` 为 `[N,L]`，无候选可传 `-1`。`votes[L,S-1]` 为随 `state_dict` 存取的 int64 buffer，无梯度；不应每轮清零。`book.level_table()` 返回各尺寸的层下标，无任何票时全部 `-1`。 |
| `predicted_size_range(logits)`；`book.gates(sizes)` | 解码整数像素端点 `[B,2]`；返回 `(neck_mask, head_mask)`，均为 `[B,L]` 布尔张量。训练是否开全层由调用者决定，不是 `book.train()` 切换的副作用。 |
| `run_selected(features, gates, operators)` | 各**独立**层的图、布尔门及每层算子 → `{层号: (原 batch 行下标, 该子批上的输出)}`。整层无样本便不调用算子；下游按保留的行、层和空间坐标解码。它不能撤销已执行的骨干、颈或检测计算。 |

在仓库根目录运行；无需下载权重或数据：

```bash
OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 python -B -m dronebench.methods.dm_efs.example
OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 python -B -m pytest -q -c /dev/null -p no:cacheprovider --noconftest dronebench/methods/dm_efs/test_dm_efs.py
```

[样例](./example.py)有两张带中心方块的合成图，每图一个框。三层各用一个真实可训练的小框头，示范一次密集前向、检测与尺寸损失反传、投票，随后不用 GT 按图路由。这里只是接口演示，框头先验及一次梯度更新不能证明检测效果。[测试](./test_dm_efs.py)另用同批不同门的样本检查实际卷积收到的子批大小、空层零调用与未选行零梯度；还验证端点损失数值、最近邻补表、持久化、空图及颈前缀与全算结果的一致性。

另可在 pytest 命令前设置 `VISDRONE_VAL_ZIP=/path/to/VisDrone2019-DET-val.zip` 运行只读实图烟测（此项另需 Pillow）；不设置时跳过这一项。本次在 Python 3.13.5、CPU PyTorch 2.9.1、pytest 9.2.0 上设置此变量后 **7 passed**。实图是 `0000001_02999_d_0000005.jpg`，1920×1080 缩放到 320×180，127 个非忽略有效框只用来核对验证损失，**没有**用验证标注更新参数或票表，亦未计算 AP 或吞吐。

## 适用条件、想验证什么

| 可直接观察的条件 | 可检验的假设与对照 |
| --- | --- |
| 输入中某组目标的宽/高已接近末端网格间距；浅层图仍看得到相应边界。 | 相同标注分桶和训练预算，先只开 EFS 对比原模型，测小目标召回、误检、显存及延迟。若浅层只剩噪声，增加一层不一定有用。 |
| 训练期间能拿到相同坐标系的 GT 和逐层预测；不同尺寸的票数确实有偏好。 | 查看每个尺寸的支持图数、最高票/次高票和补表比例。若总由一层获胜、很多尺寸没有票，或目标在不同输入尺度上发生漂移，先审查配对与尺寸覆盖。 |
| 仅看特征可以预测一图的尺度范围，且「两端对应层」足以照顾中间尺寸。 | 在保留集分别用真值端点和预测端点路由，与全开比较，分开查控制器误差与两端规则本身的漏检。可报告端点像素误差、每图激活层数、未被选中层对原本可定位目标的贡献。 |
| 后端真的能跳过未选层；批内路由差异和子批切换开销可控。 | 在相同分辨率、硬件、batch=1 下记录实际每层调用、预热后端到端延迟与峰值显存，再测异构批次。全算完再乘 mask 只能检验预测选择，不证明省算。 |

**跨任务例（待验证，不是已有结论）。** 实例分割中若细小掩膜在浅层仍有清晰边界，可用 EFS 接入一层掩膜特征；要用 DFM，需定义每实例尺寸及逐层匹配掩膜的可靠性（如 mask IoU），重新训练控制器和票表。关键点估计中，若少量采样点会吞掉细小关节，可保留高分辨率热图；需先定义实例尺度、逐层定位命中准则和可单独执行的预测层。没有这些接口时可以单试 EFS，不能沿用检测票表当作验证。

## 资源、未披露细节与本实现边界

- 新增层的代价取决于 `HᵢWᵢ`、通道和头；两轴采样间距减半时位置数约为 4 倍。票数存储为 `8 × L × (S−1)` 字节，逐图投票处理 `[N,L]`，不构造全图位置×真框矩阵。`S` 增大也会增大两支分类器的末层。要对比不同输入分辨率，重新核对尺寸标签/票表是否覆盖，不可把归一化宽高直接传入。
- 图 3 给了层组成，未给出全部宽度、激活、不同宿主的颈连接细节。本实现显式选 16 通道投影、64 隐元、FC 隐层 ReLU；参考颈的对齐、插值和卷积是工程选择，不是作者模型的逐层移植。样例中两端尺寸错序时排序；超出 `[2,S]` 的有效框尺寸饱和到边界；空图不计尺寸损失和票，全空批次返回可反传的零。τ 用闭区间 `IoU ≥ τ`。损失选 softmax focal、无额外类别权重、γ=2、两个分支相加，再对非空图取均值；文中没有规定这些全部细节。
- 式 2 只给出了每物体每层的 `t^(k,n)`，没有公开一套通用于所有检测器的候选→GT 配对算法；上游必须说明用哪个候选、匹配失败如何处理。只把训练分配器选中的正样本层当可投票层会有偏置。式 2 的投票矩阵是二值，这里以「同图同尺寸至少一个对象过阈值」解释。等票选更细层；最近邻距离相同选较小尺寸；无任何成功票时推理全开，避免拿任意层冒充已学习的表。多进程训练应汇总各 rank 的**新增票**，避免重复叠加历史票；本包不包含分布式训练器。
- 票表不强制尺度与层号单调。偶尔式 6 请求的颈前缀不覆盖另一端的头。`gates` 保留原公式，不能据此删除仍被选中头依赖的节点。[样例](./example.py)取实际依赖闭包再执行第二趟；宿主若未改造颈，应如实记录颈全算，仅跳过预测支路。`run_selected` 面向 eager 的独立算子，不保证导出或在特定设备提速。

## 论文实验出处（不是本项目结果）

Aashish Sharma，ICCV 2025，[论文页](https://openaccess.thecvf.com/content/ICCV2025/html/Sharma_DM-EFS_Dynamically_Multiplexed_Expanded_Features_Set_Form_for_Robust_and_ICCV_2025_paper.html)。[正文](https://openaccess.thecvf.com/content/ICCV2025/papers/Sharma_DM-EFS_Dynamically_Multiplexed_Expanded_Features_Set_Form_for_Robust_and_ICCV_2025_paper.pdf)图 2 示 EFS，图 3、§3 与算法 1 定义训练和式 6 路由。作者报告在 MMDetection 上以 YOLOv7 为默认检测器，也比较其他基座；数据集含 SODA-D、VisDrone、DarkFace。正文 §4 默认输入 640×640、`L=4`、`S=640`、`τ=0.5`、`λ=0.04`。表 6 为 VisDrone 验证集消融，速度按作者的单 V100 环境：

| 论文设置 | AP50 (%) | fps |
| --- | ---: | ---: |
| YOLOv7 原模型 | 47.81 | 39.71 |
| 仅 EFS，所有层全开 | 52.01 | 32.14 |
| EFS + DFM | 51.80 | 38.24 |

这张表显示 DFM 比 EFS 单用回收了一部分速度，AP50 略降；不能由此推断其他模型的收益。[补充材料](https://openaccess.thecvf.com/content/ICCV2025/supplemental/Sharma_DM-EFS_Dynamically_Multiplexed_ICCV_2025_supplemental.pdf) §2.0.1、图 3 展示浅层图；§2.0.3 的双标量回归（sigmoid、归一化尺寸与平方误差）是**对照而非主方法**，作者指出小尺寸分布下预测易聚在零附近，分类 focal 更合适；§2.0.4 报告该环境下控制器约 1.79 ms/图、整体 26.15 ms/图，极小目标仍可能缺乏表征。本包没有重跑这些实验。
