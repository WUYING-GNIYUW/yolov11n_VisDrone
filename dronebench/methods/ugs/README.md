# UGS：按离散坐标训练定位头，用定位熵的梯度细化特征

本目录只依赖 PyTorch，不导入检测框架。UGS 要解决的是**相同的坐标误差，在小目标上可能产生更剧烈的梯度变化**；不是通过改变样本分配或增设高分辨率检测层来增加候选数。它先预测坐标分布，再尝试让分布更集中，并让特征经受一次会增加定位不确定性的扰动。这里的“不确定”是**坐标分布**的不确定，不是类别分数低，也不是专指某种物体。

## 何时值得试，如何证伪

| 可观测条件 | 必需接口 | 可检验的假设与反例 |
| --- | --- | --- |
| 标注残差或边距集中在零附近，等宽箱的命中直方图只占少数格；细微偏移却改变定位质量 | 连续坐标目标、单位和可覆盖的有限量程；每个坐标独立的 K 个 logits | 固定 K、量程、匹配和训练预算，对比等宽与指数网格的占用、饱和率、坐标误差和固定尺寸桶召回。若尾部目标较多，零附近加密反而可能损失远端精度。 |
| 同一参考尺度下，小框的定位梯度波动大，且边界分布比大框更平 | 能按坐标取 softmax、记录正样本处的熵及梯度；有几何误差或覆盖率指标 | 加入 UM 后，观察相同迭代窗口的梯度方差、熵和实际定位误差。若只是错误预测变得更自信，熵虽低也不算改进。 |
| 局部遮挡或纹理混淆时，轻微特征改变就明显改变定位分布 | 可求导的中间特征，能以同一组权重在扰动后再算定位头 | 固定干净匹配，比较开／关 UR 的误差与耗时；熵梯度强度应关联这些敏感位置。若误差来自错配、系统性标注偏差，扰动不一定有益。 |

**跨任务尝试（未验证）：**例如显微图像的颗粒中心、分割轮廓的法向偏移或关键点残差，也可以是集中在零附近的连续量。只要有一致的**有符号坐标定义、监督和可复算的特征到坐标头**，就可单独尝试 IN、UM 或 UR；用中心误差、边界距离或关键点误差检验，而非照搬检测 AP。需要保留多种合理位置时，熵惩罚可能损害多峰预测。

## 原文机制与这份实现的选择

1. **IN 支持点，正文 §3.2.1 式 (9)。** 对 `K=n+1` 个点取 `y_i=−α+2αi/n`，令 `s_i=sign(y_i)·α·expm1(β|y_i|)/expm1(βα)`。这改变的是**支持点的物理位置**；不是把等宽索引加权一下。范围为 `[−α,+α]`，`α` 与目标单位相同，`αβ` 控制形状；`β=0` 取均匀极限。有奇数个点时包含零，偶数个点时零在两个中央点之间。训练和推理用同一份 `s`。
2. **编码与 CE，正文 §3.2.1 式 (8)–(11)。** 在真实网格中找包住目标 `t` 的邻点 `a,b`；右权重 `(t−a)/(b−a)`，左权重 `1−右权重`。CE 只取这两项的负对数似然。于是标签质量和为 1，按相同支持点算期望可恢复 `t`，逐坐标 CE 的 logit 梯度为 `p−q`。**解释选择：**式 (8) 印为到同一下标端点的绝对距离乘固定系数，照抄既不能保证式 (9) 非均匀格上归一，也不能保证还原坐标。本实现用文中所述相邻 two-hot 和期望解码共同确定的线性插值；式 (10) 下的 `y_i` 在 IN 模式解释为 `s_i`。超出量程的值饱和到端点，`clipped` 逐坐标标识；这是显式边界策略，不是论文给定的负距离规则。
3. **UM，正文 §3.2.2 式 (12)。** 独立对每个坐标分布取 Shannon 熵 `−Σ p_i log p_i`（自然对数），不是 `Var(s)`、阈值或检测类别的熵。通过 softmax 自动微分：对 logit 的导数为 `−p_i(log p_i + H)`；式 (13) 印出的 `−(log p_i+1)` 是对概率本身的导数，未作为手写 logit 梯度使用。
4. **UR，正文 §3.2.3 式 (14)–(16)、图 4。** 先由干净定位熵得到 `g_i=∂L_UM/∂F_i`，取一次 `ε_i=ρ·g_i/‖g_i‖₂`，再用同一定位头处理 `F_i+ε_i` 并对该输出优化。扰动集中在**对熵敏感**的激活；没有 top-k、阈值、框裁剪或推理期“高熵框再预测”。例如严格均匀分布熵最高，但对 logits 的一阶梯度为零，不能把此机制解释为按熵值硬选区。

**原文未唯一指定的 UR 细节：**式 (14) 给出扰动熵和原特征 L2 项；式 (16) 写为 `L_CE + λ L_UM + γ Σ_i L_i^ur`，没有完全展开 `L_i^ur` 或规定批／正样本归约。这里的参考选择是：每层**每张图**在非 batch 维一起归一化，零梯度位置不凭空加噪；未被路由到的整层梯度可为零。固定干净匹配，复用同一头，取扰动后的定位熵为 `L_i^ur`；`ε` 停梯度，原特征与共享头的外层反传保留。`refinement_loss` 用回调明确如何汇总扰动后各层的标量（对齐式 (16) 可返回各层熵之和）。它可显式添加 `feature_penalty·Σ_i mean_batch ‖F_i‖₂²`，默认为 0，不擅自将式 (14) 的正则系数与式 (16) 的外层 γ 重复相乘。无标签或无正样本的层可用与干净输出连图的零损失；整个批无正样本时可跳过 UR。冻结特征却要做 UR 时，必须在干净头前向前为这些特征开启求导。

## 可调用接口

入口见 [包导出](./__init__.py) 和 [独立实现](./core.py)。`...` 可含 batch、位置、坐标或其他轴；只有最后的 `K` 是分箱轴。

| 接口 | 输入 → 输出 |
| --- | --- |
| `make_support(num_bins, alpha, beta, *, device=None, dtype=torch.float32)` | 返回严格递增的 `s[K]`。应在建模时生成并缓存；外部另给的支持点也须有限、严格递增且与张量同设备。 |
| `encode_two_hot(target, s)` | `t[...] → TwoHot(left, right, right_weight, clipped)`，四项与 `t` 同形；两个索引相邻。用于查看饱和，不需构造完整标签分布。端点本身不标饱和。 |
| `localization_ce(logits, target, s)` | `[...,K]` 与 `[...] → [...]` 的逐坐标 CE。正样本筛选、权重、层间求和和归一化均由调用方决定。 |
| `uncertainty_entropy(logits)` | `[...,K] → [...]` 的定位熵，不读取标签或支持点数值。 |
| `decode_logits(logits, s)` | `[...,K] → [...]`：`Σ softmax(logits)_i·s_i`。不是 argmax、整数索引期望或 `bbox2dist`。半精度 logits 至少用 float32 计算 CE、熵和期望。 |
| `encode_ltrb(points_xy, boxes_xyxy)` / `decode_ltrb(points_xy, distances_ltrb)` | 最后维依次是 `2,4 → 4`，前维可广播，输入必须是**同一坐标系、同一单位**。输出有符号边距或原始 xyxy，不替调用方校正几何。 |
| `uncertainty_perturbations(features, um_loss, rho=0.5)` | 输入可求导特征序列与干净熵标量；输出与各层同形同类型的**增量**元组。调用方加回原特征，按需重跑定位头；不写入参数 `.grad`。 |
| `refinement_loss(features, clean_um, perturbed_um, rho=0.5, feature_penalty=0.0)` | 用上述增量调用 `perturbed_um(扰动后的特征元组)`；回调返回标量。返回的 UR 尚未乘式 (16) 外层 γ。 |

### 坐标、框外候选与原 DFL 对照

- 这里的框是连续 `xyxy`，不带“右下角 +1”。若格点 `p=(x,y)`，`ltrb=(x−x1,y−y1,x2−x,y2−y)`；解码 `xyxy=(x−l,y−t,x+r,y+b)`。**框外匹配也是有效监督**：若格点在框左侧，`l<0`，仍落到负半轴的两个支持点，不先截成零。如果 `p=(0.5,0.5)`，框为 `[1,0,2,1]`，则 `ltrb=[−0.5,0.5,1.5,0.5]`；步长 8 对应像素框 `[8,0,16,8]`。只有超出 `[−α,+α]` 的部分饱和，饱和后不能恢复原框。
- **单位是适配约定，不是论文固定参数。** 等向步长 `stride[A,1]`：像素目标框 `/stride` 和格点编码得到格单位 `ltrb`；用相同单位的支持点解码后，`decode_ltrb(...)*stride` 还原像素。若调用方已用像素格点，则支持点也须采用像素单位。裁剪／分块等情形需先转换到同一原点。
- 合法预测宽和高要求 `l+r>0`、`t+b>0`，**并不要求四边距离都非负**。函数不做绝对值、不交换端点、不截到图内。适配层应显式记录非法框、饱和率和匹配策略；推理可过滤非法框，训练应明确 IoU 对非法框的处理。在 signed 对称网格上，全相等的初始 logits 会解出近零宽高；样例用偏向正距离的 bias 给匹配一个非退化起点。这是工程选择，不是论文参数。
- 与已有 DFL 的共同点是相邻 two-hot 交叉熵与期望。原有非负等宽点 `0…K−1` **不等于** `beta=0` 的有符号网格。可给 CE／解码显式传入 `torch.arange(K, dtype=...)` 做数学对照；既有 DFL 的上界截断、IoU 项和分配器仍需保持或单独标注。按「同域等宽 → 同域非均匀 → +UM → +UR」做子消融；为箱数、量程、初始化或保留 CIoU 引入的变化分别记账。本文不含官方 YOLO11n/RFLA 的负边距配置。

## 训练、推理与资源

**训练：**干净特征 → 定位头 `[...,4,K]` → 在固定匹配的坐标上计算 CE 和 UM → 用干净 UM 对特征求导，沿单位梯度加扰动 → 用共享定位头和相同匹配计算扰动熵 → `CE + λ·UM + γ·UR` 反向。分类项由上层任务处理。关闭 UR 时跳过第二次头前向；只把 `ρ` 置零而保留 UR 权重仍会再次加入干净熵。若定位头含 BatchNorm 或 dropout，第二次前向的统计更新／随机性需由宿主明确，不能把变化算成纯扰动收益。

**推理：**只对干净特征做一次定位头前向，softmax、按真实支持点取期望并按坐标定义解码；无需 GT、熵梯度、扰动或第二次前向。匹配、阈值、NMS、区域恢复属于宿主。

**代价：**N 个位置、D 个坐标时，稠密定位输出与软最大值约需 `O(NDK)`；标签编码只保存两个索引及权重。UR 增加一次从熵到选定特征的向量–雅可比乘积、一次共享头前向，以及保存干净／扰动分支以供外层反传的内存；这里不复制定位头参数。不是稀疏推理加速方法。

[最小样例](./example.py) 使用两个已匹配位置（一内一外）、一个可训练的 1×1 卷积和一次 SGD 更新；推理在 `no_grad` 下独立解码为像素框。样例的 `K=9, α=4, β=0.5` 与正距离 bias 都不是论文最优值。从仓库根目录运行：

```bash
/home/user/work/yolo11n-env/bin/python -m dronebench.methods.ugs.example
/home/user/work/yolo11n-env/bin/python -m pytest -c /dev/null --noconftest -p no:cacheprovider -q dronebench/methods/ugs/test_ugs.py
```

[测试](./test_ugs.py) 检查式 (9) 的解析值、端点与饱和、two-hot 期望往返及 CE 梯度、熵和梯度、跨步长负边距、扰动方向／L2 半径／断梯度、空正样本和一次训练后推理。它们是数值冒烟，不是数据集指标。

## 实验出处（与本实现实测分开）

- **论文任务与模型：**作者用 PyTorch/MMDetection 在 VisDrone、SODA-A、COCO 2017、PASCAL VOC 上做检测实验；包括 FCOS、Faster/Cascade R-CNN、GFL V1、DINO-5scale、TPH-YOLOv5-x，以及旋转框检测器（正文 §4、表 1–4）。不是本包的数据／网络限制。
- **作者结果举例：**VisDrone val 表 1 的 DINO-5scale 为 35.5 → 38.1 AP；表 2 的 TPH-YOLOv5-x 在 640² 为 26.5 → 29.0，在 1536² 为 39.2 → 41.7。补充 §3 图 2 展示了两个分辨率的训练曲线，不是另一个实现或超参表。
- **作者的组件与资源对照：**Faster R-CNN/ResNet-50 的表 6 中，`L2 / CE / CE+IN / +UM / +UR` 的 AP 分别为 21.3 / 22.1 / 22.5 / 22.9 / 24.2；末项 `λ=0.5, γ=0.5, ρ=0.5`。表 7 区分 RPN 和 R-CNN 的范围、β 与 n（如 `2,1,10` 和 `5,1,5`），不是 YOLO 格单位的通用设置。表 5、§4.5 的 FCOS 在 1 张 RTX 3090、batch 2、1333×800 下训练时间 0.151 → 0.174 秒/batch；不是本包的推理延迟。
- **集成复核：**在 Python 3.13.5、torch 2.9.1+cpu 下，上述八项通用测试和最小样例已实际执行通过。样例一次 SGD 的 clean/perturbed 熵分别为 1.39595/1.41212，头梯度范数 0.36629。这里不提供训练过的权重或 YOLO11n 的精度、速度和交互结论。
