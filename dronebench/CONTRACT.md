# 五开关接入契约

固定 main `55989f76c1e85c192ba12cb3e533e3de842a2301`。配置为 JSON，例如 `{"dm_efs":true,"options":{"dm_efs":{"max_size":640}}}`；未出现的开关为 false；`--id` 是按 `dm_efs, esod, querydet, rfla, ugs` 排列的五位 0/1 字符串。训练 `python -m dronebench train --id 10000 --data VisDrone.yaml`，子消融用 `--config PATH` 替代 `--id`。方法子选项必须拒绝未知键。

顺序只有一种：整图 stem → ESOD 块 → 局部后续骨干/颈 → DM-EFS 候选层及层选择 → QueryDet 粗到细空间查询及检测 → UGS 或原 DFL 解码 → ESOD 回原图 → 原图 NMS。训练中 QueryDet/DFM 稠密监督，RFLA 或 TAL 在干净预测上分配，UGS 如启用只在训练固定分配下局部细化。`N=sum(H_l*W_l)`，层从细到粗，每层行优先。batch 文中指按当前局部图/块分组的 YOLO 字典 (`batch_idx`, `cls`, 归一化 xywh `bboxes`)；`hw` 是当前输入像素 (h,w)。

- `adapters/dm_efs/`: `DMEFSAdapter(shallow_channels, channels, strides, options, backbone_channels=...)`。传入索引 2/4/6/10 的实际骨干通道，`route` 的关键字参数 `backbone_feats` 传入这些特征给尺寸控制器。`extend_head(head)` 原地向 stock Detect 前插 P2 分支（如启用 EFS），保留 P3–P5 参数，更新 head.nl/head.stride；adapter.channels、adapter.strides 给出改变后的细到粗列表。`route(shallow,native_feats) -> (feats, level_mask[B,L] bool, state)`；训练全开，推理只真的执行选中的检测支路。记录论文式6的 requested neck vs YOLO PAN 实际全部执行；ESOD 组合时当块是样本。`aux_loss(state,batch,hw,boxes_px,feats,update_votes:bool)->scalar`，传入实际解码框 xyxy 像素 [B,N,4]，包括 UGS 路径；仅训练更新票。每 GT 每层预测归属须明示，不应引入无界 [全图位置×GT] 缓存。EMA 会同步整数 votes；提供可分开消融的 EFS/DFM，默认都启用。
- `adapters/esod/`: `ESODAdapter(shallow_channels,options)`；`epoch:int` 供训练时真值→预测选块切换。`split(shallow,hw,batch=None)->(patches,state)` 在 P2(第2号层、stride=4)之后切块；state 至少含 `hw`(块输入像素尺寸) 和 `layout`。正式验证/推理不读标签，K=0 不回退整图，模型直接跳过深层。选择等形、可喂后续 backbone/PAN、对应像素边长为32的倍数的块，避免边界或小输入生成不必要的 padding；本项目承诺输入边长≥64，能处理矩形。`local_batch(batch,state)` 映射/分组标注，不复制图；`aux_loss(batch,state)` 监督整图 ObjSeeker；`restore(decoded,state)` 接 [K,4+nc,A] 局部像素 xywh+概率，回 [B,4+nc,A'] 原图；屏蔽无效/退化候选与 padding，允许后续原图 NMS 跨块去重。记录框跨块、空块行为。留出 arg 供调整选块阈值、暖启动等。
- `adapters/querydet/`: `QueryDetAdapter(channels,strides,options)`；`forward(head,feats,level_mask) -> raw`，含原网格 `boxes[B,4R,N], scores[B,nc,N], active[B,N], feats, query_state`；真稀疏 eval，结构完整的 dense 训练。`aux_loss(raw,batch,hw)` 给 query focal loss。层 gate 只屏蔽该级的检测，不能截断随后仍需的空间查询载体。
- `adapters/rfla/`: `RFLAAdapter(strides,options).assign(points_px[N,2],stride_px[N,1],gt_labels[B,G,1],gt_boxes_px[B,G,4],valid_gt[B,G,1],active[B,N],nc)` 返回目标框像素/目标分数/正样本 bool/填充 GT 编号/diagnostics。HLA 先取 active 再排序；显式指定 YOLO 半径假设；保留 GT 无配、各阶段、框外及每 GT 个数。无 UGS 时 stock DFL 截断超出支持点的距离，不改变原 GT 的 CIoU。
- `adapters/ugs/`: `UGSAdapter(reg_max,options)`；`initialize_head(head)` 对包括新增 P2 在内的各定位头设置不退化正距离先验；`decode(pred_distri[B,N,4R],anchors[N,2]) -> xyxy [B,N,4]` 均为 cell 单位。`losses(head,raw,pred_boxes,anchors,target_boxes,target_scores,normalizer,fg,*,refine:bool)` 返回 `(iou_loss,loc_ce_loss,uncertainty_loss,refine_loss,diagnostics)`，前两项由主 criterion 分别乘 hyp.box、hyp.dfl；后两项自身乘 λ,γ。pred/target 框均为 cell xyxy，normalizer=target_scores.sum().clamp_min(1)，clean 分配固定。仅训练可求导且 refine=True 时才扰动特征并复算定位头，避免二次 BN 统计更新；eval 不求梯度、不扰动。signed 支持点、负距离与超界饱和策略需明确；默认开启三机制，可分开消融；给出真实诊断。点选和块选都不由 UGS 定义。

每份适配使用 `dronebench.methods.<名称>` 中的一阶段实现，附本目录内的单项配置例、适配说明、针对阶段二的测试；不覆盖公共注册。计算结果、训练指标都不得用论文数字或冒烟占位。
